## 📚 核心技能模块

### 模块一：事件研判（Event-Analyzer）⭐ 核心

**技能名称**: `fanli-analyzer`（范蠡商情研判系统）

**版本**: v2.0.4

**核心功能**:
- 采集：闸门/管道/背离 + 来源 URL
- 选择：三把尺子（不可逆性/影响半径/认知时差）
- 判定：A/B/C/D 四级判定
- 分析：四层拆解（望气→走卒→商贾实业→商贾操盘）

**使用场景**:
- 分析单个事件（如"帮我分析央行降准"）
- 周度事件研判（如"本周有哪些重要事件"）
- 背离分析（如"BDI 涨 + 库存高，怎么看"）

**核心链接**:
- GitHub: https://github.com/lj22503/fanli-analyzer
- ClawHub: `clawhub install fanli-analyzer`

## 📊 投资工作流

### 工作流一：每日市场扫描（交易日 09:00）

**触发命令**: `@ant 每日市场扫描`

**流程**:
1. 获取大盘实时数据（东方财富/新浪财经 API）
2. 收集北向资金数据（港交所披露易）
3. 收集经济/政策数据（财联社/华尔街见闻）
4. 分析市场情绪（涨跌家数比/涨停跌停家数）
5. 生成操作建议（仓位/配置方向/具体操作）
6. 添加风险提示

**输出位置**: 飞书知识库 - 每日市场扫描

---

### 工作流二：周度行业跟踪（周一 10:00）

**触发命令**: `@ant 周度行业跟踪`

**流程**:
1. 获取行业涨跌幅数据（东方财富 API）
2. 收集行业估值数据（PE/PB/历史分位）
3. 分析资金流向（北向/主力）
4. 整理政策/新闻
5. 跟踪行业景气度（PMI/产能利用率）
6. 生成配置建议

**输出位置**: 飞书知识库 - 周度行业跟踪

---

### 工作流三：月度组合复盘（月末）

**触发命令**: `@ant 月度组合复盘`

**前置条件**: 用户提供持仓数据

**流程**:
1. 计算组合整体表现（收益率/基准对比）
2. 持仓逐一检查（买入理由/基本面/估值）
3. 组合层面分析（集中度/相关性/风险）
4. 生成优化建议（调仓/再平衡/仓位调整）
5. 下期关注重点

**输出位置**: 飞书知识库 - 月度组合复盘

---

### 工作流四：季度深度研究（季初）

**触发命令**: `@ant 季度深度研究`

**流程**:
1. 宏观经济周期分析（GDP/CPI/PPI/PMI）
2. 行业深度研究（2-3 个重点行业）
3. 新机会筛选（新股/低估值/高成长）
4. 季度配置策略（仓位/行业/个股）
5. 风险提示

**输出位置**: 飞书知识库 - 投资框架教程

## 🎯 使用指南

### 快速开始

**1. 安装核心技能**:
```bash
clawhub install fanli-analyzer        # 事件研判（核心）
clawhub install fund-analyzer-pro     # 基金分析
clawhub install asset-allocator       # 资产配置
clawhub install cycle-locator         # 周期定位
clawhub install bias-detector         # 偏见识别
clawhub install china-masters         # 中国大师
```

**2. 配置数据源**:
```bash
# 配置 QVeris API Key
export QVERIS_API_KEY=sk-xxx

# 配置天天基金 API Key
export TTFUND_API_KEY=ttf_xxx
```

**3. 开始使用**:
```
# 事件研判
帮我分析这个事件：央行宣布降准 0.5 个百分点

# 基金分析
分析这个基金：易方达蓝筹精选

# 资产配置
帮我配置 100 万，风险偏好中等

# 周期判断
现在处于什么周期？
```
