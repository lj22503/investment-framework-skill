# duan-yongping-investor - 段永平投资智慧

**理论来源**：段永平（步步高、OPPO、vivo 创始人，价值投资家）

**功能**：基于段永平投资理念分析企业，强调"本分"、"能力圈"、"长期主义"

**触发词**：
- "段永平怎么看这家公司"
- "本分分析"
- "能力圈检查"
- "长期主义投资"

---

## 核心理念

### 段永平投资三原则

1. **本分** - 做对的事情，把事情做对
2. **能力圈** - 只投资自己懂的公司
3. **长期主义** - 买入并持有 10 年+

### 段永平选股标准

| 标准 | 说明 | 权重 |
|------|------|------|
| 商业模式 | 赚钱是否容易、持续 | 40% |
| 企业文化 | 是否"本分"、诚信 | 30% |
| 护城河 | 是否有持续竞争优势 | 20% |
| 价格 | 是否合理 | 10% |

## 输出结构

### 1. 商业模式分析

**问题**：
- 这门生意赚钱容易吗？
- 现金流好吗？
- 需要不断投入资本吗？
- 有定价权吗？

**评分**：⭐⭐⭐⭐⭐（1-5 星）

### 2. 企业文化分析（本分检查）

| 维度 | 评估 | 证据 |
|------|------|------|
| 诚信 | ✅/❌ | ... |
| 用户导向 | ✅/❌ | ... |
| 长期思维 | ✅/❌ | ... |
| 不占人便宜 | ✅/❌ | ... |
| 承认错误 | ✅/❌ | ... |

**本分评分**：✅ 本分 / ⚠️ 一般 / ❌ 不本分

### 3. 能力圈检查

**问题**：
- 你能用一句话说清公司如何赚钱吗？
- 你能预测 10 年后行业格局吗？
- 你有行业专业知识吗？
- 你能列出 3 个主要风险吗？

**结论**：在能力圈内 / 超出能力圈

### 4. 长期主义评估

**问题**：
- 你愿意持有这家公司 10 年吗？
- 10 年后公司会更大更强吗？
- 行业是朝阳还是夕阳？

**结论**：适合长期 / 不适合长期

### 5. 投资建议

| 评级 | 条件 |
|------|------|
| 强烈推荐 | 商业模式⭐⭐⭐⭐⭐ + 本分✅ + 能力圈内 + 适合长期 |
| 推荐 | 商业模式⭐⭐⭐⭐ + 本分✅ + 能力圈内 |
| 观望 | 某项不满足 |
| 不推荐 | 商业模式差 / 不本分 / 超出能力圈 |

## 使用示例

**输入**：
```
公司：贵州茅台
商业模式：高端白酒，品牌溢价高，现金流极好
企业文化：国企，品牌历史悠久
竞争优势：品牌护城河极深，产地稀缺
PE：30 倍
```

**输出**：
```
【商业模式分析】⭐⭐⭐⭐⭐
- 赚钱容易：✅ 毛利率 90%+
- 现金流好：✅ 预收款模式
- 资本投入：✅ 无需大量再投入
- 定价权：✅ 行业最强

【企业文化分析】✅ 本分
- 诚信：✅ 国企背书
- 用户导向：✅ 品质稳定
- 长期思维：✅ 百年品牌
- 不占人便宜：✅
- 承认错误：❓ 待观察

【能力圈检查】✅ 在能力圈内
- 能用一句话说清：✅ 高端白酒
- 能预测 10 年后：✅ 白酒文化持续
- 有专业知识：❓ 需自我评估
- 能列出风险：✅ 政策/健康意识

【长期主义评估】✅ 适合长期
- 愿意持有 10 年：✅
- 10 年后更大更强：✅
- 行业趋势：✅ 稳定

【投资建议】
评级：强烈推荐
理由：
1. 商业模式极佳（⭐⭐⭐⭐⭐）
2. 企业文化本分
3. 护城河深
4. 适合长期持有

段永平会说：
"茅台是门好生意，品牌就是护城河。
关键是价格是否合理，30 倍 PE 可以考虑，
但最好等到市场恐慌时买入。"
```
